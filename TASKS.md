# Tasks

## Инструменты измерений и планирования для dental CBCT

Терминология: описанный режим с кривой линией обычно называется **Curved Planar
Reformation/Reconstruction (CPR)** или **curved MPR**. В стоматологических CBCT
программах близкие названия: **panoramic reconstruction**, **panoramic curve**,
**curved slicing**. Малые срезы, построенные перпендикулярно кривой, обычно
называют **cross-sectional**, **trans-axial** или **orthogonal slices** вдоль
зубной дуги.

### Curved planar reformation / panoramic workflow

- [ ] Добавить инструмент рисования кривой на выбранном 2D-слайсе. Первый
      сценарий оптимизировать под трассировку зубной дуги на аксиальном слайсе,
      но не привязывать реализацию жестко к одной анатомической плоскости.
- [ ] Хранить кривую как набор редактируемых контрольных точек. После создания
      пользователь должен уметь перемещать, добавлять и удалять точки.
- [ ] Генерировать панорамный срез по кривой: сэмплировать volume вдоль кривой и
      разворачивать результат в плоскую 2D-текстуру.
- [ ] Настраивать толщину панорамного среза, шаг сэмплирования, режим
      интерполяции и разрешение выходной текстуры.
- [ ] Строить редактируемые нормали вдоль кривой. Нормали должны располагаться
      через равные интервалы, перемещаться вдоль кривой и редактироваться как на
      контрольных точках, так и между ними.
- [ ] Использовать каждую нормаль для генерации малого ортогонального
      cross-sectional среза. Настраивать плотность нормалей, размер
      cross-section и толщину среза.
- [ ] Добавить режим вьюпортов для активной кривой: один вьюпорт остается
      исходным слайсом с редактируемой кривой и нормалями, один показывает
      curved panoramic reconstruction, один показывает набор cross-sectional
      срезов. Начать можно с одного вьюпорта для cross-section, если так проще.
- [ ] Сделать поведение режима 2x2 предсказуемым: при выборе активной кривой
      связанные вьюпорты меняют роль под CPR workflow, а при снятии активности
      возвращаются к стандартным axial/sagittal/coronal/3D ролям.
- [ ] Добавить визуальную нумерацию нормалей и cross-sectional срезов, чтобы
      легко сопоставлять исходный слайс, панорамную реконструкцию и набор малых
      срезов.
- [ ] Добавить настройки цвета кривой, цвета нормалей, шага нормалей, размеров

- [ ] Сохранять CPR-кривые и параметры построенных видов в состоянии
